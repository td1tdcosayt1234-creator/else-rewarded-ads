API Documentation

Else Pay billing API — create charges, list products and accept Else Pay balance at checkout.

Base URLs
Billing APIhttps://api.elsepay.indevs.in
App / earn APIhttps://app.elsepay.indevs.in
Site (this page)https://elsepay.indevs.in

Authentication

Billing endpoints (/api/v1/*) are authenticated with your merchant secret key. Create a merchant in the app console (app.elsepay.indevs.in → Developers) to get a key pair:

publicKey:  else_pk_xxxxxxxx
secretKey:  else_sk_xxxxxxxx

Send the secret key on every request:

curl https://api.elsepay.indevs.in/api/v1/products \
  -H "x-else-key: else_sk_xxxxxxxx"

Endpoints under /api/pay/* are public checkout endpoints — they are called by the payer's browser and need no key.

Products

GET/api/v1/products

List your active products. Requires x-else-key.

{
  "products": [
    { "id": "prd_1", "name": "Pro plan", "price": 2.5, "currency": "USD", "active": true }
  ]
}

POST/api/v1/products

Create a product.

curl -X POST https://api.elsepay.indevs.in/api/v1/products \
  -H "x-else-key: else_sk_xxxx" -H "Content-Type: application/json" \
  -d '{"name":"Pro plan","price":2.5,"currency":"USD"}'

Charges

POST/api/v1/charges

Create a charge. Returns a checkout URL to send the payer to.

curl -X POST https://api.elsepay.indevs.in/api/v1/charges \
  -H "x-else-key: else_sk_xxxx" -H "Content-Type: application/json" \
  -d '{"productId":"prd_1","reference":"order_123","metadata":{"userId":42}}'

{
  "id": "ch_abc123",
  "status": "pending",
  "amount": 2.5,
  "currency": "USD",
  "payUrl": "https://api.elsepay.indevs.in/api/pay/ch_abc123"
}

GET/api/v1/charges/:id

Check a charge's status. Requires x-else-key. Statuses: pending, paid, failed, refunded.

{ "id": "ch_abc123", "status": "paid", "amount": 2.5, "paidAt": "2026-10-10T10:00:00.000Z" }

Checkout (payer side)

GET/api/pay/:id

Hosted checkout page for a charge. Send your user here — no key needed.

POST/api/pay/:id/confirm

Confirms payment from the payer's Else Pay balance.

Webhooks

Set a webhook URL per merchant in the console. Events are POSTed as JSON and signed:

x-else-signature: t=<unix_seconds>,v1=<hex_hmac_sha256(body, secretKey)>
x-else-key: <publicKey>

Verify by recomputing the HMAC over the raw body with your secret key and comparing to v1. Reject if the timestamp is older than 5 minutes.

const sig = crypto.createHmac('sha256', secretKey).update(t + '.' + rawBody).digest('hex');

Errors

All errors return JSON with an error field and a sensible HTTP status:

{ "error": "unauthorized" }        // 401 bad/missing key
{ "error": "not_found" }            // 404
{ "error": "insufficient_balance" } // 402
Scope note — only the billing surface is exposed on api.elsepay.indevs.in. Earn-app endpoints (wallet, tasks, ads, auth) live on app.elsepay.indevs.in. Requests for anything else on the API host return 404.
