Authentication

Merchant (billing) endpoints (/api/v1/*) use your merchant secret key. Create a merchant in the app console (app.elsepay.indevs.in → Console → Merchants) to get a key pair:

publicKey:  else_pk_xxxxxxxxxxxxxxxx
secretKey:  else_sk_xxxxxxxxxxxxxxxx   # keep secret, server-side only

Send it on every billing request:

curl https://api.elsepay.indevs.in/api/v1/products \
  -H "x-else-secret: else_sk_xxxxxxxxxxxxxxxx"

App / user endpoints use the login token (POST /api/auth/login returns it; the app also sets an httpOnly cookie):

curl https://app.elsepay.indevs.in/api/me \
  -H "Authorization: Bearer <user_token>"

Products

GET/api/v1/products

List your merchant's products. Requires x-else-secret. Returns a JSON array:

[
  { "id": "else_prod_9f3ka2bd", "merchantId": "mer_1_x8dk2", "name": "Pro Ebook",
    "type": "merchant", "country": "ALL", "price": 2.5, "active": true }
]

POST/api/v1/products

Create a product. Body: {"name": string, "price": number}.

curl -X POST https://api.elsepay.indevs.in/api/v1/products \
  -H "x-else-secret: else_sk_xxxx" -H "Content-Type: application/json" \
  -d '{"name":"Pro Ebook","price":2.5}'

# → { "product_id": "else_prod_9f3ka2bd", "name": "Pro Ebook", "price": 2.5 }

Charges

POST/api/v1/charges

Create a charge from a product (or a custom amount). returnUrl must start with http(s):// — the payer returns there after paying.

curl -X POST https://api.elsepay.indevs.in/api/v1/charges \
  -H "x-else-secret: else_sk_xxxx" -H "Content-Type: application/json" \
  -d '{"product_id":"else_prod_9f3ka2bd","returnUrl":"https://shop.com/success"}'

# → {
#   "charge_id": "ch_a7e5808b0d797d86",
#   "amount": 2.5, "currency": "USD", "status": "created",
#   "checkout_url": "https://elsepay.indevs.in/app/pay/ch_a7e5808b0d797d86"
# }

GET/api/v1/charges/:id

Check a charge. Requires x-else-secret (only your own charges). Status is created or paid:

{ "charge_id": "ch_a7e5808b0d797d86", "status": "paid",
  "amount": 2.5, "payer": "u_3_mv51ab9c" }

Checkout (payer side)

The payer must be logged in to their Else Pay account (token or cookie). Send them to checkout_url.

GET/api/pay/:id

Order preview for the payer: merchant, product, amount, status and their balance.

POST/api/pay/:id/confirm

Pays from the payer's earned balance. Safe to retry — already-paid charges return paid again instead of double-charging:

{ "ok": true, "status": "paid", "balance": 1.499,
  "returnUrl": "https://shop.com/success" }

Low balance returns 400 { "error": "low balance, earn more $" }.

Earn API (app)

Rewarded-ad flow on app.elsepay.indevs.in (Bearer token). The server enforces a full watch — instant closes return 429 watch full ad and earn nothing. Sessions are single-use and expire after 10 minutes; cooldowns and daily caps apply.

# 1) start → { "sessionId": "ad_1_x8dk2", "adSeconds": 10 }
POST /api/ads/rewarded/start            {}

# 2) after the full watch → { "reward": 0.001, "balance": 0.051, ... }
POST /api/ads/rewarded/complete         { "sessionId": "ad_1_x8dk2" }

Webhooks

Set a webhook URL per merchant in the console. On every paid charge we POST JSON and sign it. Timestamp t is milliseconds (Date.now()).

x-else-signature: t=1729161600000,v1=9f2c…(64 hex chars)
x-else-key: else_pk_xxxxxxxxxxxxxxxx

{ "charge_id": "ch_a7e5808b0d797d86", "status": "paid",
  "amount": 2.5, "product": "Pro Ebook" }

Verify with your secret key over t + "." + rawBody, and reject timestamps older than 5 minutes:

const [t, v1] = sigHeader.replace('t=','').split(',v1=');
const expect = crypto.createHmac('sha256', secretKey)
  .update(t + '.' + rawBody).digest('hex');
if (expect !== v1 || Date.now() - Number(t) > 5*60*1000) reject();

Errors

Errors are JSON with an error field. Real examples:

{ "error": "bad else secret key" }       // 401 wrong merchant key
{ "error": "invalid credentials" }        // 401 wrong login
{ "error": "login required" }             // 401 no token
{ "error": "watch full ad" }              // 429 + retryAfterSec
{ "error": "daily limit 20" }             // 429 cap reached
{ "error": "low balance, earn more $" }   // 400 can't pay
{ "error": "min $10" }                    // 400 withdraw floor
{ "error": "no charge" }                  // 404
{ "error": "maintenance" }                // 503
Scope note — only the billing surface (/api/v1/*, /api/pay/*, /api/plans, /api/payments/methods, /api/subscribe, /api/subscription/my, /api/config) is served on api.elsepay.indevs.in. Everything else there returns 404. Earn endpoints live on app.elsepay.indevs.in.

AdMob SSV (earn app)

Point your AdMob server-side verification callback at the app host (the API host does not serve this path):

https://app.elsepay.indevs.in/api/ads/ssv?user_id=<userId>&session_id=<sessionId>

Hits are credited under the same full-watch + single-use rules as the app flow.
